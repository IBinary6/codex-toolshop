description: Read web pages on demand through the official Python Fetch MCP server.

fetch preserves the official Markdown, robots, raw, max_length, and start_index pagination behavior. Follow the result guidance to continue after truncation; pass raw: true when the original page is needed.

No key is required. uvx must be on PATH. The first live call runs uvx --from mcp-server-fetch==2026.8.18 mcp-server-fetch and prepares the pinned official package. The Python backend closes with the gateway.

For configuration or runtime problems, read [README.md](../../README.md) and run this package's setup/doctor. Report only redacted status. Check tool results against sources and stop calling tools once the task has sufficient evidence.
