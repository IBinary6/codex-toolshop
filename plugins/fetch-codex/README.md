# Fetch for Codex

Version 0.1.2. Enable or disable this package independently on the Codex plugin page. It exposes only `fetch` and does not depend on other plugins being installed.

fetch preserves the official Markdown, robots, raw, max_length, and start_index pagination behavior. Follow the result guidance to continue after truncation; pass raw: true when the original page is needed.

Call this package through its MCP tools.

No key is required. uvx must be on PATH. The first live call runs uvx --from mcp-server-fetch==2026.8.18 mcp-server-fetch and prepares the pinned official package. The Python backend closes with the gateway.

## Independent private configuration

The default path is `~/.codex/fetch-codex/config.json`, or `fetch-codex/config.json` under CODEX_HOME when set. Set `FETCH_CODEX_CONFIG` to an absolute file path to override it. The template is `{ "version": 1 }`; see [config.example.json](config.example.json). This package reads only its own configuration. The combined package's RESEARCH_TOOLS_CONFIG does not apply.

Run `node scripts/setup.cjs` to create the file only if it is missing. `node scripts/setup.cjs --doctor` shows this plugin's path and redacted configuration status. Reinstalling or upgrading preserves existing configuration, and every call rereads the JSON. Never paste keys into commands, conversations, or logs.

## Runtime boundaries

Requires Node.js ≥20. This package starts one Node gateway. initialize, ping, and tools/list are entirely local: they do not access the network, start a backend, or prepare dependencies. There are no startup hooks.

Before creating the gateway, create and switch to the runtime directory beside the selected private configuration file. An absolute configuration override also determines this runtime directory. The Fetch backend inherits a stable cwd. Startup does not write to the plugin cache, and active Windows processes do not lock the cache directory and prevent upgrade renames through cwd.

The default timeout is 120 seconds. RESEARCH_TOOLS_TIMEOUT_MS accepts 1–180000 milliseconds. Input and each official response are limited to 8 MiB. Errors and results are redacted; child-process stderr is not forwarded to the conversation. Cancellation and termination stop the current wait and clean up child processes started by this package. Enabling the three MCP packages keeps three Node gateways running. Using Fetch also starts the official Python backend and possibly a uvx process.



If the combined Research Tools package is installed too, enable either the combined package or the corresponding independent package to avoid duplicate tools.

## Maintenance

This package is generated by research-tools-codex 0.1.4 using packaging/generate.cjs. The engine is the maintenance source, and runtime files in this package are self-contained copies. After changing the source, run the generator from the engine directory and then run npm test to check consistency and independence. The generator removes obsolete files only when their hashes match the previous .generated.json snapshot; unknown files, symlinks, or manual changes stop the update.
