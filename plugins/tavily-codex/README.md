# Tavily for Codex

Version 0.1.2. Enable or disable this package independently on the Codex plugin page. It exposes only `tavily_search`, `tavily_extract`, `tavily_crawl`, `tavily_map`, `tavily_research` and does not depend on other plugins being installed.

Use search/extract for finding and extracting pages; map/crawl for a defined site scope; research when the task calls for synthesis across sources. Check the original task and usage before expanding the scope.

Run `node <absolute-package-root>/scripts/command.cjs` with one `{name,arguments}` JSON object on stdin and then close input, or use `--input-file <absolute-JSON-path>`. `--list` shows this package's commands and parameters. It returns one `{content,structuredContent?,isError?}` JSON object and exits 1 on failure.

Set apiKey in this plugin's private JSON before making a live call.

## Independent private configuration

The default path is `~/.codex/tavily-codex/config.json`, or `tavily-codex/config.json` under CODEX_HOME when set. Set `TAVILY_CODEX_CONFIG` to an absolute file path to override it. The template is `{ "version": 1, "apiKey": "" }`; see [config.example.json](config.example.json). This package reads only its own configuration. The combined package's RESEARCH_TOOLS_CONFIG does not apply.

Run `node scripts/setup.cjs` to create the file only if it is missing. `node scripts/setup.cjs --doctor` shows this plugin's path and redacted configuration status. Reinstalling or upgrading preserves existing configuration, and every call rereads the JSON. Never paste keys into commands, conversations, or logs.

## Runtime boundaries

Requires Node.js ≥20. There is no MCP entry point, startup hook, or background installer; loading the plugin does not start Node. Each live call launches a short-lived command that exits when finished. --list/--help are entirely local and do not access the network or prepare dependencies.

The default timeout is 120 seconds. RESEARCH_TOOLS_TIMEOUT_MS accepts 1–180000 milliseconds. Input and each official response are limited to 8 MiB. Errors and results are redacted; child-process stderr is not forwarded to the conversation. Cancellation and termination stop the current wait and clean up child processes started by this package. Enabling the three MCP packages keeps three Node gateways running. Using Fetch also starts the official Python backend and possibly a uvx process.

[Official API](https://docs.tavily.com/documentation/api-reference/endpoint/search), [Research create](https://docs.tavily.com/documentation/api-reference/endpoint/research), [Research lookup](https://docs.tavily.com/documentation/api-reference/endpoint/research-get). Requests POST directly to api.tavily.com/search, extract, crawl, map, or research, with the Bearer key only in the request header. After creation, research polls with GET using request_id. Top-level research:{wait:false} only creates a job; research:{requestId:"original-id"} only resumes lookup (arguments:{}). Local cancellation or timeout does not cancel a created server job. Keep the returned ID to query without creating a duplicate. A failed job returns isError.

After a valid research ID is obtained, failures while waiting (HTTP, network, parsing, unknown status, local cancellation, or timeout) return redacted structuredContent with request_id, resume:true, and a safe error. isError is true and the CLI exits 1. Keep the ID and resume with the requestId form above, which sends only GET and avoids a duplicate POST. Invalid creation IDs provide no resume information.

If the combined Research Tools package is installed too, enable either the combined package or the corresponding independent package to avoid duplicate tools.

## Maintenance

This package is generated by research-tools-codex 0.1.4 using packaging/generate.cjs. The engine is the maintenance source, and runtime files in this package are self-contained copies. After changing the source, run the generator from the engine directory and then run npm test to check consistency and independence. The generator removes obsolete files only when their hashes match the previous .generated.json snapshot; unknown files, symlinks, or manual changes stop the update.
