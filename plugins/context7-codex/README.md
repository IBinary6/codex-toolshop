# Context7 for Codex

Version 0.1.2. Enable or disable this package independently on the Codex plugin page. It exposes only `resolve-library-id`, `query-docs` and does not depend on other plugins being installed.

Use resolve-library-id to locate a library, then query-docs to search it. If the user supplies an exact library ID, query it directly.

Run `node <absolute-package-root>/scripts/command.cjs` with one `{name,arguments}` JSON object on stdin and then close input, or use `--input-file <absolute-JSON-path>`. `--list` shows this package's commands and parameters. It returns one `{content,structuredContent?,isError?}` JSON object and exits 1 on failure.

The apiKey in this plugin's private JSON may be empty for anonymous access or set to a key.

## Independent private configuration

The default path is `~/.codex/context7-codex/config.json`, or `context7-codex/config.json` under CODEX_HOME when set. Set `CONTEXT7_CODEX_CONFIG` to an absolute file path to override it. The template is `{ "version": 1, "apiKey": "" }`; see [config.example.json](config.example.json). This package reads only its own configuration. The combined package's RESEARCH_TOOLS_CONFIG does not apply.

Run `node scripts/setup.cjs` to create the file only if it is missing. `node scripts/setup.cjs --doctor` shows this plugin's path and redacted configuration status. Reinstalling or upgrading preserves existing configuration, and every call rereads the JSON. Never paste keys into commands, conversations, or logs.

## Runtime boundaries

Requires Node.js ≥22.13.0 (per the published ctx7 0.6.0 package engines) and npm. There is no MCP entry point, startup hook, or background installer; loading the plugin does not start Node. Each live call launches a short-lived command that exits when finished. --list/--help are entirely local and do not access the network or prepare dependencies.

The default timeout is 120 seconds. RESEARCH_TOOLS_TIMEOUT_MS accepts 1–180000 milliseconds. Input and each official response are limited to 8 MiB. Errors and results are redacted; child-process stderr is not forwarded to the conversation. Cancellation and termination stop the current wait and clean up child processes started by this package. Enabling the three MCP packages keeps three Node gateways running. Using Fetch also starts the official Python backend and possibly a uvx process.

[Official CLI](https://context7.com/docs/clients/cli), [pinned release](https://registry.npmjs.org/ctx7/0.6.0). The first call installs ctx7@0.6.0 with npm --prefix and --ignore-scripts, then runs the official entry point directly with Node; it does not run login/setup. The runtime defaults to CODEX_HOME/context7-codex/runtime (falling back to ~/.codex). The package cache and officially supported XDG credentials/state are isolated there. The package creates its empty credential file with wx only, preserving existing files. Live commands receive the private JSON key through CONTEXT7_API_KEY and set CTX7_TELEMETRY_DISABLED=1. Verification of the official package requires npm to be discoverable in the Node distribution or PATH; if it is missing, an installation hint is returned.

If the combined Research Tools package is installed too, enable either the combined package or the corresponding independent package to avoid duplicate tools.

## Maintenance

This package is generated by research-tools-codex 0.1.4 using packaging/generate.cjs. The engine is the maintenance source, and runtime files in this package are self-contained copies. After changing the source, run the generator from the engine directory and then run npm test to check consistency and independence. The generator removes obsolete files only when their hashes match the previous .generated.json snapshot; unknown files, symlinks, or manual changes stop the update.
