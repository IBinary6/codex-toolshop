---
name: microsoft-learn-codex
description: Look up official Microsoft Learn documentation and code examples on demand.
---

Use microsoft_docs_search for official documentation, microsoft_code_sample_search for code examples, and microsoft_docs_fetch for a relevant full document. Connects to https://learn.microsoft.com/api/mcp.

No key is required.

For configuration or runtime problems, read [README.md](../../README.md) and run this package's setup/doctor. Report only redacted status. Check tool results against sources and stop calling tools once the task has sufficient evidence.
