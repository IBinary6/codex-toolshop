## Independent private configuration

The default path is `~/.codex/{{PLUGIN_NAME}}/config.json`, or `{{PLUGIN_NAME}}/config.json` under CODEX_HOME when set. Set `{{OVERRIDE_ENV}}` to an absolute file path to override it. The template is `{{TEMPLATE}}`; see [config.example.json](config.example.json). This package reads only its own configuration. The combined package's RESEARCH_TOOLS_CONFIG does not apply.

Run `node scripts/setup.cjs` to create the file only if it is missing. `node scripts/setup.cjs --doctor` shows this plugin's path and redacted configuration status. Reinstalling or upgrading preserves existing configuration, and every call rereads the JSON. Never paste keys into commands, conversations, or logs.

## Runtime boundaries

{{BOUNDARY}}

The default timeout is 120 seconds. RESEARCH_TOOLS_TIMEOUT_MS accepts 1–180000 milliseconds. Input and each official response are limited to 8 MiB. Errors and results are redacted; child-process stderr is not forwarded to the conversation. Cancellation and termination stop the current wait and clean up child processes started by this package. Enabling the three MCP packages keeps three Node gateways running. Using Fetch also starts the official Python backend and possibly a uvx process.

## Maintenance

This package is generated by research-tools-codex {{ENGINE_VERSION}} using packaging/generate.cjs. The engine is the maintenance source, and runtime files in this package are self-contained copies. After changing the source, run the generator from the engine directory and then run npm test to check consistency and independence. The generator removes obsolete files only when their hashes match the previous .generated.json snapshot; unknown files, symlinks, or manual changes stop the update.
